Host blocking fixture

The Bench points every host of the pinned test list at this server. The check calls runAdblockTest(hosts, port), which sends one request per host, the way the Turtlecute test does: a HEAD fetch with mode: 'no-cors' for /fakepage.html. The check reads the result from DevTools and the server log, not from this page, because a page cannot tell a blocked request from any other failure.
