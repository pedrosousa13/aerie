Motion spec

How every sidebar interaction moves: what animates, for how long, on which curve, what changes under reduced motion. All values are read live from tokens.json, so this page cannot drift from the tokens. Arc is the reference for feel; no Arc assets are used. Press Play on a card to run a small demo with the real values, or switch on Reduced motion (top right) to replay the reduced version everywhere.

How to read a card

What moves lists properties. Everything is transform and opacity unless the card calls out an exception. Tokens shows each motion token with its value and, where it differs, its reduced value. The curves are drawn from the easing token itself: x is time, y is progress; the dashed line is 1.0, so a spring that overshoots rises above it. Reduced is the version that runs under prefers-reduced-motion or the in-app setting.
